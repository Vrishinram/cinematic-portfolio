## 🌌 Overview

An ultra-high-performance, zero-framework **Cinematic WebGL Portfolio** built for **Vrishin Ram K** (Cybersecurity Analyst, AI Security & Red Teaming Specialist, SOC Operations). 

Unlike conventional web portfolios, this site renders an interactive, atmospheric five-scene world powered by custom GLSL shaders, camera tracking, dynamic canvas distressing, and real-time pointer physics.

## 🛠️ Local Development

Run the lightweight development server:

```bash
python tools/serve.py 5173
```

Then open **[http://localhost:5173](http://localhost:5173)** in your browser.

### Shortcuts:
- `http://localhost:5173/?t=end` — Jump directly to the settled hero composition.
- `http://localhost:5173/?t=3.2` — Jump directly to the 3.2s timeline beat.
